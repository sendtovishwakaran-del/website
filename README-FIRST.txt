THIRUPATHI REDDY — PERSONAL PORTFOLIO
=====================================

QUICK START
1. Extract the ZIP archive.
2. Double-click index.html to preview your website in Chrome.
3. Open this folder in Visual Studio Code to edit the site.
4. Upload ALL files to the root of a public GitHub repository.
5. In GitHub Settings > Pages, select Deploy from a branch > main > /(root) > Save.
6. The website will appear at https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/

FILES
index.html                     Page text, sections and links
styles.css                     Colors, fonts, layout, transitions, mobile rules
script.js                      Dark/light mode, mobile menu, skills tabs, scroll reveals
favicon.svg                    Browser icon
Thirupathi_Reddy_Resume.docx   Your original resume, offered as a download

PERSONALIZE BEFORE PUBLISHING
- To change the header name or text, edit index.html.
- To change theme colors, edit the CSS variables near the top of styles.css.
- Your name, email and phone are publicly displayed, based on the uploaded resume.
  Remove or replace any information you don't want on a public website.
- Project panels are conceptual CSS illustrations, NOT confidential client screenshots.
- Resume button downloads the original Word file. 'Save page as PDF' opens your browser print dialog.
- The resume did not include links to GitHub, LinkedIn, portfolio designs or a photo, so none were invented.
- Employment dates and education are transcribed from the supplied resume.

GITHUB PAGES
Upload the contents of this folder (not the zip). Ensure index.html is at repository root.
If you want a custom domain later, configure it from Settings > Pages and at your DNS provider.

NO BUILD OR PAID HOSTING REQUIRED
This is a static HTML, CSS and JS website. Fonts load from Google Fonts when online;
the fallback font will work offline.
